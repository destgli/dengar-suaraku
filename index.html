🔒 Privasi & Perlindungan Data

Kami berkomitmen melindungi data pribadi kamu sesuai Undang-Undang No. 27 Tahun 2022 tentang Perlindungan Data Pribadi (UU PDP).

1. Prinsip Dasar Perlindungan Data

Platform "Dengar Suaraku" mengumpulkan dan memproses data pribadi berdasarkan prinsip-prinsip yang diamanatkan UU PDP, yaitu: legalitas, pembatasan tujuan, minimalisasi data, akurasi, pembatasan penyimpanan, integritas, kerahasiaan, dan akuntabilitas.

Pasal 16 UU PDP No. 27/2022: "Pemrosesan Data Pribadi harus didasarkan pada dasar pemrosesan yang sah, termasuk persetujuan eksplisit dari Subjek Data."

2. Data yang Dikumpulkan

Kami hanya mengumpulkan data yang benar-benar diperlukan untuk layanan:

  • Data Identitas: Nama, email, nomor mahasiswa (untuk verifikasi)
  • Data Disabilitas: Jenis disabilitas (opsional, hanya untuk pencocokan mentor & aksesibilitas)
  • Data Aktivitas: Postingan forum, laporan aksesibilitas, pencarian beasiswa
  • Data Suara: Rekaman suara untuk fitur Speech-to-Text — tidak disimpan permanen, langsung dikonversi
Pasal 20 UU PDP: "Pengumpulan Data Pribadi dilakukan secara terbatas dan spesifik, sah secara hukum, patut, dan transparan."

3. Data Sensitif: Disabilitas

Data jenis disabilitas termasuk dalam kategori data pribadi sensitif yang mendapatkan perlindungan lebih ketat. Data ini tidak pernah dibagikan kepada pihak ketiga tanpa persetujuan eksplisit. Akses terbatas hanya untuk fitur pencocokan mentor dan rekomendasi beasiswa.

Pasal 4 ayat (2) UU PDP: "Data Pribadi yang bersifat spesifik meliputi data kesehatan, data biometrik, data disabilitas, dan lainnya yang wajib mendapatkan perlindungan lebih ketat."

4. Hak-Hak Subjek Data (Anggota KMH)

Setiap anggota KMH sebagai subjek data memiliki hak penuh atas datanya, sesuai Bab V UU PDP:

  • ✅ Hak untuk mendapatkan informasi tentang data yang dikumpulkan
  • ✅ Hak untuk mengakses dan menyalin data pribadinya
  • ✅ Hak untuk memperbaiki data yang tidak akurat
  • ✅ Hak untuk menghapus data (right to be forgotten)
  • ✅ Hak untuk menarik kembali persetujuan kapan saja
  • ✅ Hak untuk menolak pemrosesan data untuk keperluan tertentu
Pasal 67-71 UU PDP: Mengatur hak subjek data secara menyeluruh, termasuk hak penarikan persetujuan dan hak penghapusan data.

5. Keamanan Teknis Data

  • 🔐 Enkripsi end-to-end untuk semua data yang ditransmisikan
  • 🔐 Data tersimpan di server terenkripsi (AES-256)
  • 🔐 Two-factor authentication untuk akun admin
  • 🔐 Audit log akses data secara berkala
  • 🔐 Data suara diproses secara lokal dan tidak diunggah ke server

6. Tanggung Jawab Pengelola (KMH sebagai Pengendali Data)

KMH bertindak sebagai Pengendali Data Pribadi yang wajib menerapkan langkah teknis dan operasional untuk menjamin keamanan data, serta melaporkan kebocoran data dalam waktu 14 hari sesuai ketentuan UU PDP.

Pasal 35-43 UU PDP: Kewajiban Pengendali Data termasuk perlindungan teknis, organisasional, dan pelaporan insiden keamanan data.

7. Kontak & Pengaduan

Untuk pertanyaan privasi atau pengaduan terkait data pribadi, hubungi tim KMH di: privasi@komunitasmatahati.org atau kunjungi sekretariat di Jl. Rungkut Asri XIII No. 16, Surabaya.
